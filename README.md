# DSA

Two new LeetCode problems per day, solved in Python 3.10+.

Solutions live in `easy/`, `medium/`, or `hard/`. Filenames contain the problem
number and descriptive title. Each file includes a straightforward (lengthy)
solution, an optimal interview solution, complexity notes, useful comments, and
a `main()` that calls and checks both approaches. The `Solution` class provides
the LeetCode entry point.

Run any problem directly, for example:

```sh
python3 easy/0001_two_sum.py
```
